# Data directory

Store downloaded NYC TLC monthly files in `data/raw/` (create the directory locally), derived intermediate data in `data/interim/`, and final prepared features/targets in `data/processed/`.

The entire data directory is ignored by Git, except for this README.

Start with [yellow_tripdata_2024-01.parquet](https://d37ci6vzurychx.cloudfront.net/trip-data/yellow_tripdata_2024-01.parquet).
